# PBO-AutoTuner
Automatic per-core Curve Optimizer (PBO) tuner for AMD Ryzen 5000/7000/9000 on Windows. Finds the most negative stable CO for each core, resumes where it left off after crashes and reboots, and outputs a BIOS-ready table. Built on CoreCycler's tools. English/Turkish UI. Validated on a 9950X3D only; use at your own risk.
